# Support

InboxFoundry is community-maintained open-source software with no guaranteed response time or Gmail compatibility, and it can't recover deleted browser storage or downloads.

Start with the [README](README.md). For bugs, open a GitHub issue using synthetic data, and include your browser and Gmail language, the output of **Check Gmail compatibility**, and **Copy diagnostics**. Both contain counts and status only. Never post mailbox content. Security reports go through [SECURITY.md](SECURITY.md).
