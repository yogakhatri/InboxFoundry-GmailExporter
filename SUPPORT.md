# Support

InboxFoundry is community-maintained open-source software.

For usage questions, read [README.md](README.md), [docs/EXPORT_FORMAT.md](docs/EXPORT_FORMAT.md), and [docs/TESTING.md](docs/TESTING.md). For reproducible bugs, open a GitHub issue using synthetic data. Include extension/Chrome version, operating system, Gmail language, scope mode, expected behavior, actual behavior, and sanitized diagnostics.

Do not post mailbox content, addresses, subjects, filenames, Gmail URLs, internal IDs, tokens, or exported archives. Security reports belong in the private process described by [SECURITY.md](SECURITY.md).

The project does not currently promise an SLA, guaranteed Gmail compatibility, regulatory compliance, or recovery of deleted browser storage/downloads.
